# Нагрузочное тестирование WebTours (k6)

## Описание проекта

Данный проект демонстрирует проведение нагрузочного тестирования веб-приложения WebTours с использованием инструмента k6.

WebTours — это демонстрационная система бронирования авиабилетов, которая часто используется для обучения нагрузочному тестированию и анализа производительности веб-приложений.

Система под тестированием:

http://webtours.load-test.ru:1080/WebTours/

Инструмент тестирования:
k6


## Цель тестирования

Целью тестирования является проверка стабильности работы системы при одновременной работе нескольких пользователей.

В рамках теста анализируются:

- время ответа сервера
- процент ошибок
- стабильность обработки запросов
- поведение системы при увеличении нагрузки


## Сценарий тестирования

Во время теста виртуальные пользователи выполняют следующий сценарий:

1. Отправка HTTP GET запроса к главной странице WebTours
2. Проверка корректности ответа сервера (HTTP статус 200)
3. Пауза перед следующей итерацией


## Профиль нагрузки

Нагрузка задаётся по следующему сценарию:

Фаза увеличения нагрузки (Ramp-up)  
0 → 10 виртуальных пользователей за 1 минуту

Фаза стабильной нагрузки (Steady load)  
10 пользователей в течение 8 минут

Фаза снижения нагрузки (Ramp-down)  
10 → 0 пользователей за 1 минуту

Максимальное количество пользователей:  
30 виртуальных пользователей


## Результаты тестирования

Всего выполнено запросов: 1700

Процент ошибок: 0%

Среднее время ответа: 56.91 ms

Медиана времени ответа: 56.99 ms

90-й перцентиль: 60.41 ms

95-й перцентиль: 61 ms

Максимальное время ответа: 86.14 ms

Количество запросов в секунду: 14.16 req/s


## Анализ результатов

Все HTTP-запросы были успешно обработаны сервером.

Процент ошибок составил 0%, что свидетельствует о стабильной работе системы на данном уровне нагрузки.

Время ответа остаётся стабильным на протяжении всего теста. Значения среднего времени ответа и перцентилей отличаются незначительно, что говорит об отсутствии резких скачков задержки.

Максимальное время ответа также остаётся в пределах нормального диапазона.


## Вывод

В ходе нагрузочного тестирования система WebTours продемонстрировала стабильную работу при нагрузке до 30 одновременных пользователей.

Основные результаты:

- 100% успешных запросов
- отсутствие ошибок
- стабильное время ответа
- отсутствие деградации производительности

На текущем уровне нагрузки система работает корректно и не демонстрирует признаков перегрузки.

Для более глубокого анализа производительности рекомендуется проведение stress-тестирования с увеличением количества виртуальных пользователей для определения предельной нагрузки системы.
