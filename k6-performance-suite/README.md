# k6 Performance Suite

## О проекте

Данный репозиторий содержит нагрузочные тесты, реализованные с использованием k6.

Цель проекта — моделирование реального пользовательского поведения и проверка производительности backend-сервиса.

Основной бизнес-сценарий:
**логин → просмотр товаров → добавление в корзину → оформление заказа → проверка заказа**

---

## Архитектура

Тестируемая система:
- Backend API (Node.js)
- PostgreSQL (основная БД)
- Redis (кэш)
- Docker окружение

Инструменты:
- k6 — генерация нагрузки
- Prometheus — сбор метрик
- Grafana — визуализация

---

## Тестовые сценарии

### Smoke тест

Параметры:
- 1 виртуальный пользователь (VUs)
- 1 итерация

Что проверяется:
- Доступность сервиса (/health)
- Успешный логин
- Получение списка товаров
- Добавление товара в корзину
- Получение корзины
- Создание заказа
- Получение заказа

Проверки (checks):
- HTTP статус-коды
- Наличие токена авторизации
- Наличие товаров
- Успешное создание заказа

---

## Thresholds (SLA)

В тесте заданы следующие ограничения:

-  http_req_failed < 1%
-  p95 response time < 1000 ms

### Подход к тестированию

Используется end-to-end сценарий (бизнес-флоу)
Выполняется базовая корреляция данных (token, orderId)
Проверяется не только статус ответа, но и содержимое
Учитываются корректные HTTP статусы (200, 201)
