# Нагрузочное тестирование WebTours

## Цель проекта

В рамках проекта проведено нагрузочное тестирование системы бронирования
билетов **WebTours** с использованием двух инструментов:

-   k6
-   Apache JMeter

Цель проекта - реализовать одинаковый бизнес‑сценарий нагрузки и
сравнить результаты работы инструментов.

------------------------------------------------------------------------

## Тестовый сценарий

Сценарий эмулирует действия пользователя:

1.  Открытие WebTours
2.  Переход на главную страницу
3.  Авторизация пользователя
4.  Поиск рейсов
5.  Выбор рейса
6.  Бронирование билета
7.  Покупка билета

------------------------------------------------------------------------

## Профиль нагрузки

-   Количество виртуальных пользователей: **10**
-   Ramp‑up: **60 секунд**
-   Длительность теста: **\~10 минут**

## Вывод

Оба инструмента успешно справились с заданной нагрузкой.

**k6** - Более стабильные показатели времени ответа - Удобная интеграция
с CI/CD - Подходит для автоматизации нагрузочного тестирования

**Apache JMeter** - Более высокий throughput - Удобный GUI для
построения сценариев - Широкие возможности конфигурации тестов

## CI/CD

Для проекта настроен автоматический запуск нагрузочного теста через
**GitHub Actions**.

Pipeline выполняет:

-   checkout репозитория
-   установку k6
-   запуск тестового сценария
-   проверку SLA (thresholds)
