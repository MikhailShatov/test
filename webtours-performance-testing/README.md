# Нагрузочное тестирование WebTours

## Цель проекта

В рамках проекта проведено нагрузочное тестирование системы бронирования билетов **WebTours** с использованием двух инструментов:

- k6
- Apache JMeter

Цель — реализовать один и тот же бизнес-сценарий нагрузки и сравнить результаты работы инструментов.

---

# Тестовый сценарий

В тесте реализован следующий пользовательский путь:

1. Открытие главной страницы
2. Авторизация пользователя
3. Переход на страницу поиска рейсов
4. Поиск авиабилетов
5. Выбор рейса
6. Покупка билета

---

# Профиль нагрузки

Параметры теста:

- 10 виртуальных пользователей
- разгон нагрузки — 60 секунд
- основная нагрузка — 10 минут
- сценарий выполняется циклически

---

# Используемые инструменты

- **k6** — инструмент для нагрузочного тестирования
- **Apache JMeter** — инструмент для нагрузочного тестирования
- **Grafana** — мониторинг системы
- **InfluxDB** — хранение метрик

# Локальный запуск тестов

## Запуск k6
k6 run -e WT_HOST=http://webtours.load-test.ru:1080 k6/webtours_k6.js

## Запуск JMeter
Запуск JMeter
jmeter -n -t jmeter/diplom_jm.jmx
